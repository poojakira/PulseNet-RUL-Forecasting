# PulseNet RUL Forecasting (Archived)

**Status: archived experimental reference; not production-ready.**

This repository contains remaining-useful-life (RUL) forecasting experiments and
an unsupported FastAPI prototype built around NASA C-MAPSS data. It is not an
ML-security product, has not been validated on physical equipment or live fleet
telemetry, and must not be used to make maintenance, grounding, or safety
decisions.

The repository was removed from the active product portfolio on 2026-08-11.
See [ARCHIVE.md](ARCHIVE.md) for the evidence and decision record.

## What remains

- Data loading and preprocessing for the checked-in C-MAPSS FD001 files.
- Experimental regression and anomaly-detection model implementations.
- Benchmark scripts that can write local evidence artifacts.
- Unit tests for portions of the model, pipeline, API, and security helper code.
- An unsupported API prototype retained for source review only.

The checked-in C-MAPSS files were generated by simulation. NASA describes the
dataset as multivariate engine trajectories with sensor noise and injected fault
progression; this is not evidence from an operating fleet. Source retrieved
2026-08-11: [NASA Open Data Portal](https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data).

## Explicit non-capabilities

- No production deployment is supported.
- No real-world maintenance outcome has been measured.
- No reliability, availability, latency, throughput, accuracy, or safety claim
  is made by this README.
- The API prototype does not establish secure multi-tenancy. A caller-controlled
  tenant header is not tenant authorization.
- Statistical out-of-distribution checks do not prove adversarial robustness.
- Hash-chained local logs are tamper-evident under limited assumptions; they are
  not immutable storage or non-repudiation.
- Kubernetes, Terraform, Docker, and dashboard assets were removed because they
  had not passed deployment, load, recovery, or independent security review.

## Reproduce for research only

Requirements: Python 3.11 or 3.12 and `uv`.

The historical lock contains known vulnerable dependencies. Prefer static review.
If reproduction is necessary, use a disposable unprivileged environment with no
credentials, no production data, and no network exposure after installation.

```bash
uv sync --locked --extra dev
uv run python scripts/verify_archive.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 uv run pytest \
  -p pytest_asyncio.plugin -q -o addopts='' --ignore=tests/test_api.py
```

The benchmark script writes a new local artifact and can consume substantial
CPU time:

```bash
uv run python benchmark/deep_rul_benchmark.py \
  --output /tmp/pulsenet-fd001.json --overwrite
```

Treat every generated value as specific to the exact commit, data hashes,
dependency lock, random seed, hardware, and command. Do not compare it with a
published paper unless preprocessing, target construction, split, and scoring
protocols have been independently shown to be equivalent.

## Safety

Do not connect this code to operational equipment, maintenance systems, or an
internet-facing endpoint. Do not use its categorical maintenance suggestions as
instructions. Review [SECURITY.md](SECURITY.md), [SECURITY_AUDIT.md](SECURITY_AUDIT.md),
and [RUNBOOK.md](RUNBOOK.md) before running historical code.
